# Grand Theft Tunisia — The Feed

A small original browser game prototype inspired by the uploaded GTA-style Tunisia concept art.

## Run

No build step is required.

1. Open `index.html` in a modern browser.
2. Use **WASD** to move around Tunis.
3. Walk to glowing evidence markers and press **E**.
4. Use **F/J** for the journal, **M** for the map, **C** for characters, **I** for inventory, **T** for stats, and **P** for settings.
5. Press **ESC** to close panels.

For best results, serve the folder with any static server (for example VS Code Live Server).

## Project structure

- `index.html` — game shell and HUD
- `style.css` — neon UI inspired by the supplied reference
- `game.js` — game loop, movement, mission, evidence system, map and panels
- `reference.jpg` — the uploaded reference image
